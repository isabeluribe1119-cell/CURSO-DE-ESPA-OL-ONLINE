# Lista de comprobación de calidad docente

> Úsala para revisar una clase (grabada con consentimiento o recordada con detalle), un material o tu práctica general cada trimestre.

## Planificación

- [ ] La clase tiene un objetivo comunicativo concreto y comprobable.
- [ ] El objetivo se relaciona con el plan individual del estudiante.
- [ ] Hay una progresión del input a la producción.
- [ ] Hay un plan B y una actividad de reserva.

## Interacción y clima

- [ ] El estudiante habla al menos la mitad del tiempo (más en clases de conversación).
- [ ] Uso preguntas abiertas y espero antes de reformular.
- [ ] Compruebo la comprensión con preguntas de concepto, no con «¿entiendes?».
- [ ] El clima permite equivocarse sin miedo.

## Gramática y lengua

- [ ] Presento el significado antes de la forma (o junto a ella).
- [ ] La práctica exige atención al significado.
- [ ] Hay al menos una tarea comunicativa con propósito.
- [ ] Respeto la variedad del estudiante y la presento sin jerarquías.

## Corrección y evaluación

- [ ] La corrección sigue el acuerdo con el estudiante.
- [ ] Combino corrección inmediata (práctica controlada) y diferida (producción libre).
- [ ] Registro errores recurrentes.
- [ ] Hay un criterio de logro y una autoevaluación.
- [ ] El progreso es visible para el estudiante (informes, grabaciones, portafolio).

## Materiales

- [ ] No contienen errores lingüísticos (ortografía, tildes, ¿?, ¡!, concordancias).
- [ ] La variedad es coherente.
- [ ] Las instrucciones son breves y tienen ejemplo.
- [ ] Incluyen clave de respuestas.
- [ ] Los elementos de terceros tienen licencia compatible y atribución.
- [ ] Si usé IA, revisé lingüística y didácticamente todo el contenido y verifiqué datos y fuentes.

## Accesibilidad

- [ ] Texto con tamaño suficiente y buen contraste.
- [ ] La información no depende solo del color.
- [ ] Los audios tienen transcripción cuando es posible.
- [ ] Las instrucciones son claras para estudiantes con distintas necesidades.

## Ética y profesionalidad

- [ ] No prometo resultados garantizados.
- [ ] Mis credenciales son veraces.
- [ ] Protejo los datos personales y solo grabo con consentimiento.
- [ ] Con menores: comunicación con el adulto responsable por canales profesionales.
- [ ] Respeto mis límites de horario y carga de trabajo.
