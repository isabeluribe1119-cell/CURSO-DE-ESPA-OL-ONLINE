# Lista de comprobación para clases infantiles

> Basada en los Módulos [5](/modulos/05-ninos/) y [12](/modulos/12-gestion-profesional/).

## Antes de empezar con un nuevo niño o niña

- [ ] He hablado con el adulto responsable (no con el menor) y acordado el canal de comunicación.
- [ ] Conozco la edad, las lenguas de casa, el perfil lector y los intereses del niño.
- [ ] La familia ha compartido, si lo desea, información relevante para adaptar las clases.
- [ ] Tengo el consentimiento escrito para cualquier grabación o uso de imágenes (o no grabo).
- [ ] La familia conoce mis políticas de horario, cancelación y comunicación.
- [ ] He explicado el papel del adulto durante la clase (ayudar, no responder por el niño).

## Preparación de cada clase

- [ ] Objetivo claro y realista (5–8 palabras nuevas o 1–2 estructuras).
- [ ] Rutinas de inicio y cierre preparadas (canción, marioneta, saludo).
- [ ] Actividades de 3–8 minutos que alternan movimiento y calma.
- [ ] Al menos una actividad en la que se puede responder sin hablar.
- [ ] Materiales visuales grandes y claros; nada de texto si el niño no lee.
- [ ] Actividad de reserva por si algo no funciona.
- [ ] Vídeos y enlaces revisados por completo antes de mostrarlos.
- [ ] Fondo y vestimenta adecuados; cámara y audio comprobados.

## Durante la clase

- [ ] Instrucciones de una en una, con gesto y modelo.
- [ ] Espero 5–10 segundos antes de ayudar.
- [ ] Celebro los logros concretos («¡Dijiste *vaca*!»).
- [ ] Reformulo los errores en lugar de señalarlos.
- [ ] Respeto el periodo de silencio si lo hay.
- [ ] Ofrezco pausas de movimiento.
- [ ] Observo y anoto: comprensión, producción, atención, intereses.

## Actividades por perfil

| No lector (4–6) | Aprendiendo a leer (6–7) | Lector (8–10) |
|---|---|---|
| ☐ TPR / Simón dice | ☐ Rimas y palmas de sílabas | ☐ Lecturas cortas y cómics |
| ☐ Busca y trae | ☐ Bingo imagen + palabra | ☐ Pistas escritas / detective |
| ☐ Marioneta que se equivoca | ☐ Emparejar imagen y palabra | ☐ Mensajes cortos |
| ☐ Canciones con gestos | ☐ Veo, veo con sonidos | ☐ Proyectos (mi animal fantástico) |
| ☐ Pintar al dictado | ☐ Cuentos con palabras repetidas | ☐ Juegos de palabras |

## Después de la clase

- [ ] Anoto logros, dificultades y ajustes para la próxima clase.
- [ ] Envío a la familia (si está acordado) un mensaje breve con lo trabajado y una idea para casa.
- [ ] Si observo dificultades persistentes, las registro de forma objetiva y, si procede, las comento con la familia **sin diagnosticar**.

## Señales para revisar el plan

- [ ] El niño se muestra ansioso o no quiere conectarse.
- [ ] Las actividades son demasiado fáciles o demasiado difíciles de forma sistemática.
- [ ] La participación del adulto interfiere.
- [ ] La duración de la clase supera la atención del niño.
