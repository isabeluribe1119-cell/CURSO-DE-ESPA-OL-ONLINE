# Aula Abierta ELE — Recursos para enseñar español online

**Aprende a planificar, enseñar, evaluar y desarrollar tu negocio como tutor de español online.**

Curso gratuito y colaborativo para tutores de español online: metodología, gramática, planificación, materiales, evaluación y desarrollo profesional.

Autora y creadora: **Isabel Uribe** · *Spanish for your life*

🌐 **Curso publicado:** https://isabeluribe1119-cell.github.io/CURSO-DE-ESPA-OL-ONLINE/ *(disponible cuando GitHub Pages esté activado; ver [docs/PUBLICACION.md](docs/PUBLICACION.md))*

> Un proyecto educativo abierto que reúne conocimientos, estrategias, materiales y herramientas prácticas para ayudar a tutores de español online a mejorar sus clases, fortalecer su metodología y desarrollar una práctica docente sostenible. El acceso al contenido es gratuito y la comunidad puede contribuir a mejorar los recursos mediante colaboraciones, sugerencias y donaciones voluntarias.

---

## Qué incluye

| | |
|---|---|
| **17 módulos** con **163 lecciones** | Fundamentos · Adquisición de segundas lenguas · Gramática tradicional, cognitiva y comunicativa · Planificación · Niños de 4 a 10 años · Adolescentes y adultos · Currículo A1–C2 · Perspectiva panhispánica · Materiales · Metodologías · Evaluación · Gestión profesional · Plataformas · Marca personal · Precios e ingresos · Inteligencia artificial · Proyecto final |
| **37 clases modelo completas** | Todas las combinaciones de nivel (de Pre-A1 a C2) y edad (niños de 4 a 6 y de 7 a 10, adolescentes y adultos); clases de prueba, canciones, rutinas, proyectos, debates, pronunciación, mediación y español para la salud |
| **19 recursos descargables** | Plantillas, rúbricas, fichas, listas de comprobación, hojas de cálculo (CSV con fórmulas), banco de prompts y plantilla de proyecto final |
| **Cinco secuencias didácticas integradas** | Ser/estar, indefinido/imperfecto, indicativo/subjuntivo, por/para, pronombres de objeto |
| **Herramientas web** | Buscador, filtros por nivel, edad, metodología y tipo de recurso, progreso guardado en el navegador (sin cuentas), cuestionarios interactivos, modo oscuro, impresión |
| **Referencia** | Glosario de ELE, bibliografía por temas con estado de verificación, preguntas frecuentes |

> ⚠️ **Completar el curso no constituye una titulación oficial ni una acreditación profesional.**

## Para quién

Personas que quieren empezar a enseñar español a extranjeros; tutores en italki, Preply, Superprof u otras plataformas; docentes que enseñan a niños, adolescentes o adultos; creadores de materiales; profesionales que quieren construir una marca educativa y diversificar ingresos de forma ética.

## Principios

- **Rigor accesible:** se distingue la evidencia consolidada, las hipótesis en debate y la experiencia práctica.
- **Honestidad:** sin promesas de resultados, sin cifras inventadas; la información cambiante se marca y se fecha.
- **Perspectiva panhispánica**, con ejemplos de Colombia y de otros contextos.
- **Abierto:** código MIT, contenidos CC BY-SA 4.0.

## Desarrollo rápido

```bash
npm ci        # instalar dependencias
npm run dev   # construir y ver en http://localhost:4321
npm test      # construir + comprobaciones de calidad
```

Requisitos: Node.js ≥ 20. Guía completa: [docs/DESARROLLO.md](docs/DESARROLLO.md).

## Estructura

```
content/      Contenido del curso en Markdown (módulos, clases, recursos, páginas)
src/assets/   Estilos, JavaScript, iconos e imágenes
scripts/      Generador estático, comprobaciones, servidor local
docs/         Desarrollo, publicación, donaciones, citación, pendientes
.github/      Flujo de publicación en GitHub Pages y plantillas de colaboración
```

## Publicación

El flujo `.github/workflows/pages.yml` construye, comprueba y publica el sitio en GitHub Pages desde la rama por defecto. Requiere activar una vez **Settings → Pages → Source: GitHub Actions**. Ver [docs/PUBLICACION.md](docs/PUBLICACION.md).
